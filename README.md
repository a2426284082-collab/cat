# 管理端与手机布局增量补丁 3.12.1

适用：已有3.12.0（或重装3.12.1）的项目。此包是增量补丁，不包含旧版站点主体；不要整包覆盖仓库，也不要只上传压缩包。

1. 解压到单独文件夹，在该文件夹打开CMD：

```bat
node apply-update.cjs "D:\1.前期开发的\杂物\新建文件夹 (2)\cat-main"
```

2. 更新器会先核验文件并检查原代码锚点，再备份与合并。遇到锚点变化会停止，不会盲目覆盖。原Agent逻辑、Worker入口、wrangler.jsonc、原迁移、环境变量和密钥文件保留；依赖未新增，仅更新package版本元数据。
3. 回到原项目执行：

```bat
npm test
npm run test:components
npm run build
```

4. 提交更新器产生的所有实际文件变化到GitHub，再按原流程部署。后台首次访问会用现有SALES_DB自动创建3张附加表；不需要重建D1或手动修改原表。本更新器不部署、不访问线上数据库。

如果本地项目仍低于3.12，请先合并已有3.12更新包，不要手工只改版本号绕过检查。备份位于原项目workspace-backups目录。如需撤销，请先停止本地开发服务，再执行：

```bat
node restore-update.cjs "原项目路径" "更新器输出的完整备份路径"
```

恢复会覆盖这次更新涉及的源文件，保留线上数据库。若更新后还自行改过代码，请先另存副本。

## 本次改动

- 标记已售：页面即时切换并显示同步状态；只锁定当前行，防重复提交。请求失败/超时时页面回退并提示刷新核对，不能把页面回退理解成飞书已撤销。管理列表每次显示40条，按需加载；短期缓存、并发合并和手动强制刷新减少重复读取。
- 销售管理：行级操作不再全量重载；支持姓名/尾号/状态搜索、修改姓名及到期日期、原有额度/封禁/重置/重发、最近调用记录。
- 完整激活码：新生成或重发的码使用AES-GCM加密存档，默认列表仍显示尾号。管理员点击“查看/复制”后显示，45秒或窗口失焦后收起。历史哈希码无法还原，需管理员手动重发并重新分发；重发会使旧码和旧登录失效，不会自动续期。
- 工作台设置：品牌名/副标题、AI标题及提示文字、说明与运营联系方式；默认卡片加价、手机密度、默认图数及尺寸；新销售默认额度、浏览器绑定数、AI冷却、新码默认有效天数；拼图、下载面板、单猫海报、速算器开关。
- 手机：默认紧凑模式，压缩留白、卡片、工具栏与海报编辑区；后台宽表格在窄屏改为账号/猫咪信息卡。输入字体保留16px，避免移动浏览器聚焦时自动放大。可在设置中切回标准密度。

设置通过已有库存响应携带公开配置，不增加每次编辑的额外全站请求。保存后刷新工作台即可加载；默认加价不会覆盖销售已保存在本浏览器的个人设置。工具开关控制工作台入口与Agent调度，不把公开库存素材变成私有访问。

## 激活码加密与数据

沿用已有ADMIN_SESSION_SECRET派生加密密钥，无须新增环境变量。不要随意更换该密钥；更换后，先前存档的码可能无法解密，需要重发。旧销售码的哈希认证和D1数据不因加密存档而迁移或删除。

新增附加表：workbench_config（配置）、sales_key_secrets（加密码/有效期）、workbench_admin_events（操作类型与账号标识）。日志不存完整激活码，销售接口不返回完整码。全站限额、个人额度、设备绑定与冷却继续由服务端校验；旧的两张核心表和已有会话保留。

## 验证与边界

本地可用基线上的接口/算法及组件回归通过，覆盖即时反馈、重复提交、同步失败回退、旧刷新结果隔离、加密/查看/重发、到期与动态绑定上限、配置保存和账号资料。增量更新器另验证哈希、锚点预检、备份、回退及Agent文件保留。

当前可执行的完整本地源码是3.10基线；本补丁以相同锚点增量适配3.12，未取得最新3.12全站源码进行整站回归，因此安装后仍需在你的原项目执行上述构建和测试。更新器不会用3.10主体覆盖你的3.12 Agent。真实浏览器预览服务不可用，手机尺寸与线上飞书延迟仍需实机验收；没有访问真实账号或执行上线。

随包admin-controls-preview.html是用实际管理端组件生成的离线交互示例，不连接真实飞书、D1、账号或AI，可查看管理端和模拟同步失败。静态示例不代表实机网络性能。
