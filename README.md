# 销售工作台 3.12.0 · 销售工具调度与简单连续对话

日期：2026-10-28。本包只更新本地源码，尚未上线。

## 本次功能（3.12）

中间输入不再固定进入挑猫接口。常见任务先在浏览器识别并调用已有的具体功能；复杂业务表达才请求DeepSeek识别白名单工具。模型只返回结构化工具参数，浏览器再次验证，不能执行代码、任意URL、管理员操作或外部发布。

### 可直接调用

- 做图：随机从真实有图在售库选2至9只（优先品种多样），可按预算/品种筛选素材。输入“随便挑几只猫做一张小红书展示图”，直接打开实际拼图，不强制索要预算。
- 连续调整：换成4只/6只、换一批、打乱顺序、换排版、不要价格、恢复价格、改统一加价、改某只标价、加店名、改城市、镜像、方图/竖图、复制文案、请求下载。拼图弹窗右侧也能输入后续指令，预览继续固定显示。
- 挑猫与话术：预算/品种/性别继承当前客户条件，后续说“预算改成2000”“换成英短”“再便宜点”；选择单猫写夸赞/保价话术，选两只对比。短编号先解析成当前库存真实完整ID，重复短编号要求明确，不猜编号。
- 资料工具：打开某只资料、原素材下载面板、单猫零售价海报、运费/收款速算器，或生成可复制的查库口令。可说“看第二只资料”“下载#017视频”“#017运费200报价1350预付款300帮我算利润”。下载仍需浏览器实际允许保存，复制口令不等于锁定库存。
- 全局：开关对客模式、筛选/刷新/换批猫源、修复本应用图片缓存、打开手册。合作与售后回答沿用现有手册原文检索，不让模型编造政策；检索不明则提示负责人确认或查看FAQ。

示例：

```text
随便挑几只猫做小红书展示图
换成四只
不要价格
加上杭州猫舍
下载这张图
```

生成图与手动按钮共享同一个编辑器，后续指令保留手动修改的单只报价、招牌和已选猫。原有独立按钮继续可用；收藏、备忘录、带练仍隐藏。

### 简单连续对话与数据位置

- 浏览器sessionStorage按销售账号（访客按设备）隔离，保存当前任务的真实ID、参数、报价和有限文字；不保存图片Blob。
- 记录最近8轮、每条最多600字，当前需求摘要200字，海报文案最多1600字。通常在当前标签页刷新后可恢复；30分钟无操作后过期。新任务、退出或切换账号清空上下文，切换销售身份会关闭旧编辑窗口。
- 发送模型时仅携带有限任务摘要、最多9个ID及最近最多3条用户输入（每条120字），不重放完整历史或图片；同一会话的指代与参数在本地解析。
- 存储不可用时提示，当前页面仍可操作，刷新不保证恢复。跨设备/跨浏览器同步不在本版范围。原localStorage备忘录、练习进度和激活设备数据不会被“新任务”删除。
- 待返回请求遇到新任务、账号变更或当前任务变化时，旧结果不会覆盖新任务。已请求模型的调用仍按原规则计次。

### 计费与风控

本地工具（做图、调整、资料、下载入口、速算、手册）不扣AI次数，AI冷却或余额为0也能执行；首次打开仍等待授权检查完成。

已有挑猫话术/单猫保价/对比/营销文案的模型请求计1次。无法明确本地识别的业务指令会进行一次模型工具识别，也计1次；如果识别后还需另一次模型生成，先显示“执行已识别任务（1次）”按钮，等冷却后由销售明确点击，绝不在一条识别请求后自动串联第二次收费调用。

复用原D1事务额度、全站上限、15秒冷却、设备校验、封禁/急停与调用日志。工具识别也写D1审计。无关指令及格式错误在模型前拦截；模型返回非法工具/字段/编号时不执行，模型已发出则按原规则计1次，不自动重试。

### 已知边界

这是受控销售工具助手，不是任意浏览网站或执行任意动作的通用Agent。闲聊、管理员封禁/激活码操作、改库存、自动发布到微信/小红书均不开放。当地运费必须核实后填写，不自动产生真实订单；规则回答以现有手册与订单协议为准。

“好看”选图目前优先有照片和品种多样，不做视觉审美评分；自然语言本地规则和模型理解均可能需要澄清。不同工具的能力仍取决于当前在售资料和已有界面。

## 图片与海报修复

定位到可导致“某个浏览器特别慢”的旧库存缓存和反复解码原图问题，以及访客授权检查错误触发状态重置、令免费拼图关闭的问题。浏览器差异可能也涉及扩展、存储状态与设备内存，尚未实机复现用户浏览器的闪退，不能断言只有缓存一个原因。

- 原图读取最多同时2个，原图解码串行；列表先显示12张，近视口才加载，离开视口释放显示资源。
- 预览图压缩到最长边960像素，内存缓存最多32张/16MiB，浏览器图片缓存最多36张/16MiB/24小时；读取和请求设超时，坏图可单张重试。
- 图片地址升级缓存版本；服务端仅缓存成功且仍属当前库存的图片，按飞书应用隔离；库存响应不再让浏览器长期使用旧列表。
- 海报编辑防抖、串行合成，显示照片进度；取消任务、换图及关闭时释放画布。默认下载直接保存已经预览的成品，不再重复合成；需要时可勾选“下载时重新微调构图（稍慢）”。
- 工具栏“修复图片缓存”仅清理本应用图片缓存并刷新库存，不清激活状态、报价、客户备注、练习进度。避免用浏览器“清除此网站全部数据”解决图片问题。
- 访客重新聚焦页面不会再因授权检查反复关闭免费拼图。已有AI收费授权变化仍取消付费任务，避免串账号显示。

上述限制用于降低峰值内存与重复请求，不能保证所有旧浏览器、超大照片或弱网环境都不会失败。海报使用压缩预览素材合成1080像素PNG；原始高清文件另走下载通道，不承诺放大后增加原图细节。

## 跟进备忘录

猫卡右上角“⭐ 收藏/记报价”打开“今日跟进备忘录”，保存真实完整猫咪ID、短编号、当时底价、我的报价、客户备注和日期。同一猫可为多位客户分别记录；报价与备注即时保存，支持历史记录、删除确认与JSON导出。

拼图默认在报价图成功下载后批量记入备忘录，可取消勾选；同一编辑会话重复下载不重复添加，也不覆盖客户备注。对客模式隐藏星标、抽屉与内部操作。

数据仅保存在当前浏览器localStorage，不写服务器、不跨设备同步；最多300条。空间不足会提示，建议导出备份；浏览器全部数据清除后无法恢复。

## 详情页实用工具

1. 下载原视频与高清图：可依次下载或逐项下载。视频使用原文件流式下载，不再误存原有播放接口的4MiB片段；限制200MiB、60秒上游超时。浏览器可能拦截多个下载，逐项链接可补存。下载不会去除素材原有水印。
2. 单猫详情海报：1080×1600 PNG，包含照片、品种、性别、月龄、疫苗资料、简述与可编辑零售价；未提供的资料显示待核对，不编造疫苗或健康承诺，屏蔽文案里的合作底价信息。
3. 复制报单口令：同时包含短编号与完整真实编号、底价，请群主核对在售状态并拍实时视频；复制本身不会自动锁库存。
4. 运费与收款速算：选择省份、方式，填写核实后的运费检疫与其他费用，计算总拿货成本、客户应付、尾款和预计价差收益。运费可读取本浏览器对应路线的上次估算，系统不冒充实时运价，不把价差保证成净佣金。收款用“预付款”表述，支付节点按实际协议填写；复制给客户的内容不包含合作底价或利润。
