这份兼职需要你做什么

  1. 这是一份线上兼职，不收押金、培训费和入职费用。
  2. 建议准备至少两个能正常发内容、回复消息的平台账号。
  3. 你可以做小红书、抖音、快手、闲鱼、贴吧、微博、知乎、朋友圈、QQ或微信群，不限制只做一个平台。
  4. 需要持续发布和找客户。偶尔发一条以后就不管，通常很难卖出去。
  5. 有人咨询时，及时回复。客户准备购买后，再联系负责人确认库存、结算价和运费。
  6. 没有无责底薪。卖出去以后，你赚取自己售价和结算价之间的差价。

第二步 · 看懂所有销路
客户可以从很多地方来

找客户的6种方法

自己发布内容

把单猫视频、预算推荐、品种对比和养猫问题发到小红书、抖音、快手、微博、知乎等平台。

怎么做：每天发1—2条。标题写清品种、预算和城市，内容结尾问一句“你在哪个城市、预算多少”。有人点赞、收藏或提问时及时回复。

搜索需求，主动联系

搜索“想买猫、求猫、预算买猫、哪里买猫、XX城市买猫”等词，优先看最近几天发布的内容。

怎么做：每天找10条明确需求，选3—5个人认真回复。先回答对方的问题，再询问城市、预算和喜欢的品种。

在商品平台挂售

在闲鱼等当前允许的平台发布真实猫咪资料，让正在找商品的人直接看到。

怎么做：保持3—5条有效商品，一只猫对应一条。写清品种、性别、年龄、所在地和报价；售出后及时修改或下架。

评论区寻找客户

在热门猫咪视频、买猫避坑、品种介绍和预算推荐内容下面，经常有人留言询价、求推荐或说明自己想买。

怎么做：每天查看10条相关内容的最新评论。只联系明确说想买、问价格或求渠道的人；针对他的原话回复，不复制同一句广告。

朋友圈和群聊

朋友圈、QQ/微信群、校园群、本地群和养猫群都可以带来熟人或同城客户。

怎么做：朋友圈每天发1条；群里先看群规，有人求猫时再推荐。不要连续刷屏，也不要见人就私聊。

合作和转介绍

宠物店、美容店、猫咖、寄养店、摄影师、群主、朋友和成交客户，都可能介绍准备养猫的人。

怎么做：每天联系1—2个合作对象。成交客户收猫稳定后再回访，请他帮忙介绍；奖励方式先和负责人确认。

4需要时再看

常用话术和售后处理

前面的步骤会做以后，遇到具体问题再来这里查。

遇到问题再查

常用话术

先正常回答客户的问题，再顺着询问城市、预算和想要的类型。下面的话可以复制后按实际情况修改。

1了解客户需求

客户一上来只问价格
可以呀。你在哪个城市？大概预算多少，比较喜欢什么品种和颜色？我按你的情况帮你挑几只。
客户说“随便看看”
没问题，你可以先看看。为了不一次发太多，你比较喜欢什么品种或颜色？预算大概在哪个范围？我先挑两三只给你。
客户不知道选什么品种
可以先不用确定品种。你更喜欢圆脸、长毛还是短毛？家里有没有小孩或其他宠物？再告诉我预算，我按你的情况帮你筛。
客户预算比较低
这个预算我先帮你看看有没有合适的，不一定要追求最热门的颜色。你更在意品种、外形还是距离？如果预算可以稍微调整，也可以一起告诉我。

2介绍、报价和解答顾虑

客户想多看几只
可以。我先按你的预算和喜欢的类型，再挑2—3只差别比较明显的给你。你看完告诉我最喜欢哪一只，我再补详细视频。
客户想看更多视频
可以的。你把喜欢的猫咪截图或编号发我，我先确认它现在是否在售，再尽量补充现有活动视频。需要指定动作的视频，我也可以帮你问一下。
客户问能不能便宜
我先帮你确认一下这只目前的价格和库存。你能接受的预算大概是多少？如果这只超出预算，我也可以给你找同类型、价格更合适的。
客户问为什么价格不一样
同一个品种也会因为年龄、性别、颜色、品相和所在地不同，价格有差别。你更在意哪一项？我可以按同一预算给你放在一起比较。
客户问异地怎么运输
可以先告诉我收货城市。我拿猫咪编号帮你确认能不能运输，以及实际运费多少。运输方式和时间要以确认后的安排为准。
客户担心猫咪不真实
理解，你谨慎一点是对的。我可以把现有原图、活动视频、猫咪编号和所在地发给你。你想进一步确认哪一部分，也可以直接告诉我，我再帮你问。

3跟进和促成下单

客户说“考虑一下”
没问题，你可以先考虑。喜欢的话我可以再补充视频，或者帮你看看有没有同类型、预算更合适的。
客户看过以后没有回复
前面发你的几只，有没有比较喜欢的？如果是价格、颜色或距离不合适，你可以直接告诉我，我重新按你的要求筛，不用勉强选。
客户选中的猫已经卖了
这只刚确认已经不在售了，不好意思。我可以按同样的品种、颜色和预算重新找2—3只给你，先确认在售以后再发，尽量不耽误你。
客户准备下单
好的，我现在用这只猫的编号和你的城市确认最终库存、结算价格及运费。确认清楚以后，我再把下单需要的信息一次发给你。

4收猫回访和售后

客户收到猫后正常回访

找到客户以后再判断

什么样的客户算有效

先去找客户，有人来咨询后，再用下面的标准决定要不要继续花时间跟进。

可以继续跟进
  1. 已经成年；
  2. 明确想养猫、选猫、买猫或比较不同猫；
  3. 愿意说明城市、预算或喜欢的品种；
  4. 愿意继续看图片、视频或了解价格；
  5. 近期确实有购买打算。
暂时不用反复跟
  1. 未满18岁；
  2. 只说“在吗”“看看”，之后不再回复；
  3. 加上以后马上删除；
  4. 只是好奇，没有养猫或买猫打算；
  5. 重复咨询，或者之前已经登记过；
  6. 所在地区暂时无法运输，以负责人回复为准。（海南省、内蒙古、新疆、西藏的客户不要）
不要等客户自己出现

每天发布、寻找需求、认真回复、回访客户。做满七天，再看哪种方法最适合自己。
